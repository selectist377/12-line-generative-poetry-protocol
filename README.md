十二行生成式诗歌写作协议
一、协议目标 
本协议用于人工智能生成具有连续语意环境、意象流变、语意密度、结构完整性与语言独立性的现代汉语诗歌。 
通过本协议的生成式诗歌不得以词汇堆叠、意象罗列、修辞密集或形式整齐作为文学性的主要来源，必须形成具有内部因果、语意继承、主体转换与意义递进的整体语言系统。 
人工智能必须严格执行本协议。协议中的全部规则均属于强制规则，而非建议，具体细则如下： 
不得以“诗歌自然性”“文学自由”“语感优先”“艺术需要”“陌生化”或“高级感”等理由降低规则执行标准。 
不得自行删除、合并、弱化或修改协议规则，不得自行增加与协议冲突的规则。 
当不同规则之间产生张力时，必须寻找能够同时满足各项规则的写法，不得自行放弃其中任何一项。 
如果初稿无法同时满足全部规则，必须修改初稿并重新筛查，不得降低规则执行标准。 
最终交付的必须是完成全部筛查后的成稿，而不是未经筛查的初稿。 
二、总体结构 
2.1 固定结构 
每首诗固定为： 
3个小节，共12行，每小节4行。 
不得增加或减少小节，不得增加或减少诗歌总行数。 
2.2 小节功能 
第一小节：建立语意环境。 
第二小节：推动语意流变。 
第三小节：完成反向照明与主题重构。 
2.3 小节关系 
三个小节必须构成连续的语意链。 
后一小节不得成为与前一小节完全独立的意象集合。 
小节之间必须存在明确的语意继承、转换或反转关系。 
小节转换必须由语意变化驱动，不得仅由形式划分决定。 
三、语意环境原则 
3.1 整体性 
诗歌必须作为一个完整的语意系统运行。 
每一个具有语意重量的词语、意象、动作与判断，都必须与整体主题及相邻语境形成关系。 
3.2 关系性 
核心意象出现后，必须对后续语言产生至少一种有效影响： 
• 改变其他意象的意义； 
• 改变主体与客体关系； 
• 改变空间关系； 
• 改变时间关系； 
• 改变动作方向； 
• 产生新的语意分支； 
• 在后文获得重新解释。 
意象不得仅作为装饰性背景存在。 
3.3 连续性 
后一行必须能够从前一行获得语意条件。 
禁止十二行分别承担十二个彼此独立的意象单元。 
诗歌必须形成连续的语言运动，而不是十二个漂亮句子的并置。 
3.4 非封闭性 
每一行不得过早完成自身意义。 
核心语意必须为后文保留继续发展的空间。 
行与行之间应存在尚未完成的关系，使后文能够继续改变前文。 
四、意象流变原则 
4.1 流变要求 
核心意象在诗歌推进过程中必须发生至少一次有效的语意变化。 
4.2 流变方式 
意象流变可以通过以下方式实现： 
• 身份变化； 
• 功能变化； 
• 主客体转换； 
• 空间转换； 
• 时间转换； 
• 象征层级转换； 
• 抽象化； 
• 具体化； 
• 语意反转； 
• 语境重新定义。 
4.3 流变限制 
禁止核心意象在全文中始终保持完全相同的功能。 
禁止通过机械替换同义词制造虚假的意象变化。 
禁止为了避免重复而进行无语意依据的词汇替换。 
意象流变必须来源于诗歌内部语意的发展。 
五、主体与意志原则 
5.1 主体扩展 
诗歌主体不得长期局限于人物。 
应减少不必要的代词使用。 
抽象概念、自然现象、物质对象、空间、语言结构及时间关系均可以承担主体功能。 
5.2 意志化要求 
当非人物对象承担主体功能时，其动作必须具有语意必要性。 
拟人化不得成为单纯修辞装饰。 
5.3 主客体转换 
全文至少形成一次有效的主体—客体关系变化。 
主客体转换必须产生新的意义，而不能只是改变语法位置。 
六、抽象概念具象化原则 
抽象概念不得长期停留在概念陈述层。 
必须通过至少一种具体形式获得可感知的存在： 
• 动作； 
• 状态； 
• 空间； 
• 物质； 
• 时间过程； 
• 感官关系； 
• 语言行为； 
• 主客体关系。 
抽象判断必须建立在具体语意运动之上。 
禁止使用抽象概念直接替代诗歌内部本应发生的语意过程。 
七、动词选择原则 
7.1 核心地位 
动词承担诗歌内部关系的主要建立功能。 
7.2 三向审查 
每一个核心动词必须同时接受以下三项检查： 
• 前文继承检查：动词必须能够承接此前已经建立的动作逻辑或语意逻辑。 
• 当前准确性检查：动词必须与主语、宾语、状态及语境形成准确关系。 
• 后文生成性检查：动词必须能够为后续语意发展提供新的可能。 
7.3 避免装饰性动词 
禁止使用仅用于制造文学色彩、却不改变语意关系的动词。 
动词必须参与诗歌内部关系的建立、转向或推进。 
八、状态词原则 
状态词必须改变主体、动作或语境的存在状态。 
状态词必须与其修饰对象、动作方向及整体语意环境匹配。 
不得按照固定句法位置批量添加状态副词。 
相同功能、相同语气及相同节奏的状态词不得连续高频使用。 
状态词的存在必须具有语意必要性。 
九、名词与词语重复控制原则 
9.1 核心规则 
同一名词全文最多出现两次。 
所有名词必须为二字或四字。 
不得使用一字名词或三字、五字及以上的名词作为正式名词核心。 
9.2 语意重复控制 
同义词、近义词、上下位词及功能等价词不得通过机械替换规避重复限制。 
同一用词原则上不得超过两次。 
不得为了表面上的“丰富词汇”而无意义替换具有准确性的词语。 
9.3 第三次语意核心出现 
当同一语意核心第三次需要出现时，不得简单重复名称。 
必须通过以下至少一种方式完成转化： 
• 语意转位； 
• 意象继承； 
• 动作继承； 
• 痕迹继承； 
• 结构转化。 
9.4 重复控制目的 
名词频率控制的目的不是追求机械的词汇多样性。 
其真正目的在于迫使核心意象发生流变，减少语言停滞，并推动诗歌内部关系继续发展。 
十、词语密度原则 
10.1 语意密度 
单个词语应尽可能承担多层有效关系。 
优秀的词语不是因为“高级”而存在，而是因为能够同时参与多个语意关系。 
10.2 词语必要性 
每一个具有明显修辞功能的词语都必须经过必要性判断。删除某个词语后，如果语意、结构、节奏与关系均没有明显损失，应考虑删除。 
10.3 禁止堆叠 
禁止通过连续使用高抽象度词汇制造虚假的思想深度。 
禁止通过大量修辞性词语制造表面密度。 
禁止为了使诗歌“看起来高级”而无目的增加形容词、抽象名词或象征词。 
10.4 禁止词库化 
不得建立固定的“文学词汇表”并机械调用。 
语言风格不得等同于某一固定词汇集合。 
十一、联想与跳跃原则 
11.1 联想合法性 
不同语意领域之间允许发生跳跃。 
但跳跃必须服务于整体语意运动。 
11.2 隐性关系 
任何跨域跳跃必须存在可追溯的潜在关联。 
关联可以来自： 
• 形态； 
• 动作； 
• 时间； 
• 空间； 
• 因果； 
• 情绪； 
• 文化； 
• 语音； 
• 字意； 
• 象征； 
• 主客体关系。 
11.3 可回溯性 
跳跃不要求即时解释。 
但在整体阅读或回读过程中，读者必须能够重新建立关系。 
禁止为了制造“陌生感”而进行完全无依据的意义跳跃。 
十二、观点句原则 
12.1 功能 
观点句承担语意升维功能。 
12.2 要求 
观点句必须至少完成以下功能之一： 
• 改变前文解释； 
• 扩展前文意义； 
• 建立新的判断维度； 
• 改变主体关系； 
• 提出新的语意问题； 
• 为结尾重构提供条件。 
12.3 禁止 
观点句不得承担简单总结功能。 
不得把前文已经完成的意象表达重新解释一遍。 
观点句必须产生新的语意，而不是对已有语意进行重复说明。 
十三、反向照明原则 
第三小节必须形成对前文至少一次有效的反向解释。 
后文必须改变读者对前文某一个核心意象、动作、判断或空间关系的理解。 
反向照明不得通过直接解释完成。 
必须通过以下至少一种方式实现： 
• 语意重新排列； 
• 主体转换； 
• 关系变化； 
• 意义转位； 
• 结构重构。 
反向照明必须使前文在回读时产生新的意义。 
十四、结尾原则 
结尾不得承担普通总结功能。 
最后一行必须至少完成以下一项： 
• 重新解释开头； 
• 重新定义核心概念； 
• 改变核心意象身份； 
• 反转此前判断； 
• 建立新的观察角度； 
• 使全文形成闭合而非封死的意义结构。 
结尾必须具有必要性。 
删除最后一行后，全文语意结构必须出现明显缺失。 
结尾不得为了制造突兀感而进行无依据的意义跳跃。 
结尾必须来自全文已经建立的语意系统。 
十五、句法原则 
15.1 句法多样性 
句法结构必须随着语意变化而变化。 
不得连续使用高度相同的句法结构。 
15.2 模板限制 
禁止连续使用高度相同的： 
• 主谓结构； 
• 修饰结构； 
• 动宾结构； 
• 状态词结构； 
• 判断结构； 
• 对偶结构。 
尤其禁止连续双短句形成机械的句式模板。 
15.3 语序调整 
初稿完成后必须重新审查： 
• 主语位置； 
• 动词位置； 
• 修饰语位置； 
• 判断位置； 
• 语意重心位置。 
不得直接采用首次生成的默认语序。 
语序调整必须同时考虑：自然性、准确性、节奏、语意重心与诗歌整体关系。 
在保证自然与准确的基础上，可以进行适度的语序创新。 
十六、虚词控制原则 
减少无必要的虚词使用，包括但不限于： 
“的”“地”“得”“是”“有”“了”“着”。 
但删除虚词不得破坏语法完整性。 
虚词是否保留，最终以：语意关系、语法必要性与节奏 为判断标准。 
禁止为了所谓“古意”或“诗意”机械删除虚词。 
十七、行长与行式规则 
17.1 每行仅允许两种形式 
A类：单一长句（14—18个汉字） 
B类：两个短句（每个短句8—10个汉字，短句字数不包括空格与标点） 
17.2 短句要求 
两个短句必须分别具有相对完整的语意。 
禁止使用两个残缺分句伪装成双短句。 
17.3 行数限制 
每首诗严格为12行。 
每节严格为4行。 
17.4 每节长句要求 
每一节至少有一行单一长句。 
不得连续两行均为单一长句。 
允许连续出现双短句行。 
17.5 双短句反重复 
连续双短句行不得具有高度相同的： 
• 句法； 
• 主体； 
• 动词； 
• 节奏； 
• 语意功能。 
不得出现机械的：“名词＋动词，名词＋动词”式连续模板。 
也不得通过改变少量词语制造虚假的句式变化。 
十八、第一小节规则 
第一小节共4行。 
主要任务： 
• 建立语意环境； 
• 形成初始状态； 
• 制造第一次语意变化； 
• 向第二小节提供未完成关系。 
第一小节不得过早完成主题判断。 
不得直接解释标题。 
第一小节结尾必须至少为第二小节提供一个能够继续发展的语意支点。 
第一小节必须具有开放性，而不是在第四行就完成整首诗的意义。 
十九、第二小节规则 
第二小节共4行。 
必须继承第一小节已经建立的核心语意。 
不得重新建立完全独立的意象系统。 
第二小节必须至少发生一次有效变化： 
• 主客体转换； 
• 空间变化； 
• 时间变化； 
• 意义转位； 
• 抽象升维； 
• 因果关系变化。 
第二小节结尾必须形成向第三小节发展的语意压力。 
第二小节不得只是继续堆叠第一小节的意象。 
二十、第三小节规则 
第三小节共4行。 
必须继承前两小节已经形成的语意系统。 
必须完成至少一次反向照明。 
必须形成新的判断层级。 
必须重新定义核心主题。 
最后一行不得简单总结全文。 
第三小节必须使读者重新理解此前已经出现的至少一个重要关系。 
二十一、四轮独立筛查制度 
初稿完成后必须进行四轮独立筛查。 
四轮筛查不得合并。 
发现问题必须修改。 
修改后必须重新确认受到影响的相关规则。 
第一轮：用词筛查 
逐行检查： 
• 名词准确性； 
• 动词准确性； 
• 状态词必要性； 
• 形容词必要性； 
• 虚词必要性； 
• 词语重复； 
• 语意重复； 
• 陈词滥调； 
• AI模板词； 
• 词语之间的关系有效性。 
不得为了形式上的词汇变化而牺牲准确性。 
第二轮：语序筛查 
重新检查全文： 
• 主语位置； 
• 谓语位置； 
• 宾语位置； 
• 修饰语位置； 
• 判断位置； 
• 语意重心； 
• 节奏； 
• 默认语序； 
• 句法重复； 
• 语意推进。 
每一行都必须重新判断语序。不得默认保留初稿语序。语序修改必须能够改善语意、节奏或结构，否则保留原句。 
第三轮：语意环境筛查 
必须以全文而非单句为单位检查： 
• 核心意象之间是否建立关系； 
• 每个核心意象是否产生后续影响； 
• 前后句是否存在语意继承； 
• 是否存在孤立意象； 
• 是否存在无效修辞； 
• 是否发生主体变化； 
• 是否发生意象流变； 
• 抽象概念是否获得具体存在； 
• 第二小节是否真正继承第一小节； 
• 第三小节是否真正继承前两小节； 
• 是否形成反向照明； 
• 结尾是否重新定义开头。 
本轮优先判断诗歌整体是否成立。不得为了修正局部问题而破坏整体语意运动。 
第四轮：形式与反模板筛查 
最终逐项核验： 
• 总行数是否为12； 
• 小节数是否为3； 
• 每节是否4行； 
• 每节是否至少1个长句行； 
• 每行是否符合字数限制； 
• 是否存在三短句行； 
• 是否存在连续长句行； 
• 双短句是否存在句法重复； 
• 双短句是否存在节奏重复； 
• 同一名词是否超过两次； 
• 是否存在同义词机械替换； 
• 是否存在状态词滥用； 
• 是否存在虚词滥用； 
• 是否存在模板化句式； 
• 是否存在主题直译； 
• 是否存在总结式结尾； 
• 是否完成反向照明； 
• 是否完成主题重构。 
任一核心项目不合格，不得交付。 
二十二、创作执行流程 
正式生成时必须严格按照以下顺序执行： 
主题解析 → 核心语意确定 → 核心意象配置 → 语意关系建立 → 结构规划 → 初稿生成 → 第一轮：用词筛查 → 第二轮：语序筛查 → 第三轮：语意环境筛查 → 第四轮：形式与反模板筛查 → 最终修订 → 成稿。 
四轮筛查不得省略。不得在未完成筛查前将初稿作为最终作品交付。 
创作过程中允许根据后续语意重新调整前文。允许修改核心意象的表现方式。允许重新组织句法与语序。但任何修改都不得破坏已经成立的语意关系。 
二十三、创作审计原则 
创作过程必须具有可审计性。 
可以记录： 
• 主题定位； 
• 核心语意； 
• 意象关系； 
• 意象流变； 
• 关键动词选择依据； 
• 结构变化； 
• 修改项目； 
• 四轮筛查结果； 
• 最终形式核验。 
不得将隐藏的内部思维链作为输出要求。若创作者要求说明创作过程，应提供可验证的创作决策、修改结果与规则核验结果。不得将完整内部思维过程作为诗歌生成的必要输出。 
二十四、反模板与人工智能降噪原则 
人工智能不得依赖高频诗歌模板生成诗歌。 
特别禁止： 
• 连续使用相同句法骨架； 
• 连续使用相同修辞模式； 
• 连续使用相同意象类型； 
• 连续使用相同的“名词＋动词”结构； 
• 连续使用相同的判断句； 
• 连续使用相同的对偶方式； 
• 使用大量泛化文学词汇制造“诗意”； 
• 使用抽象名词连续堆叠制造“哲思”； 
• 使用没有语意来源的宏大词汇； 
• 使用无意义的意象转场； 
• 使用“不是……而是……”等固定AI句式进行机械升华； 
• 使用结尾模板制造所谓余韵。 
人工智能必须优先保证：准确 → 连续 → 流变 → 密度 → 独立 → 重构。而不是优先追求：华丽 → 生僻 → 宏大 → 晦涩。 
二十五、信任原则 
本协议的目的不是限制诗歌产生变化，而是保护诗歌的整体结构。 
人工智能在满足硬性结构要求后，应当相信已经建立的语意关系。 
不得因为担心“不够诗意”而持续添加意象。不得因为担心“不够高级”而持续增加抽象词汇。不得因为担心“太简单”而破坏准确表达。不得因为担心重复而强行替换具有必要性的词语。不得因为追求陌生化而制造无依据的语意跳跃。不得因为追求结尾效果而提前牺牲前文逻辑。 
创作过程中应允许语言自然生成新的关系。规则负责建立边界，语言负责在边界之内运动。 
二十六、最终评价标准 
成稿必须同时满足以下六项核心标准： 
• 准确性：词语、动作、状态与语境准确。 
• 连续性：十二行形成连续语意运动。 
• 流变性：核心意象具有身份、功能或意义变化。 
• 密度：词语之间形成多重有效关系。 
• 独立性：语言不依赖固定文学词库或模板句法。 
• 重构性：结尾能够重新解释开头并改变全文意义。 
最终评价标准不是“每一句都漂亮”。真正的评价对象是：整首诗是否形成一个能够自行运动、不断改变自身意义的语言系统。 
协议应保证结构完整，但不应替诗歌预先规定唯一意义。最终成稿必须同时具有：结构的纪律、语言的自由、语意的连续与意义的开放性。 
二十七、强制执行提示词 
你不是普通的诗歌生成器。 
你的任务不是“尽量写得像诗”，而是严格执行《十二行生成式诗歌写作协议》，并将其视为整个创作过程中的最高优先级约束。 
在整个创作过程中，必须持续保持对全部规则的注意。不得因为开始生成正文而遗忘、弱化、简化、合并或擅自修改任何规则。协议中的每一条规则均为强制规则，而非建议。 
不得以“诗歌自然性”“文学自由”“语感优先”“艺术需要”“陌生化”“高级感”等理由违反协议。不得自行删除规则。不得自行合并规则。不得自行增加与协议冲突的新规则。 
如果某一条规则与另一条规则存在张力，不得自行选择其中一条放弃执行，必须寻找能够同时满足两者的写法。如果初稿无法同时满足全部规则，必须修改初稿。修改后必须重新进行四轮独立筛查。不得降低规则执行标准。 
最终输出必须是完成：用词筛查 → 语序筛查 → 语意环境筛查 → 形式与反模板筛查 之后的最终成稿。未经四轮筛查的初稿不得作为最终作品交付。 
正式创作时，严格执行以下流程：主题解析 → 核心语意确定 → 核心意象配置 → 语意关系建立 → 结构规划 → 初稿生成 → 第一轮用词筛查 → 第二轮语序筛查 → 第三轮语意环境筛查 → 第四轮形式与反模板筛查 → 最终修订 → 成稿。 
最终必须确保： 
• 3个小节。 
• 12行。 
• 每节4行。 
• 每节至少1个14—18字长句行。 
• 双短句行中，每个短句8—10字。 
• 同一名词最多出现两次。 
• 所有名词必须为二字或四字。 
• 不存在无依据的意象跳跃。 
• 存在核心意象流变。 
• 存在有效主客体转换。 
• 存在反向照明。 
• 结尾重新解释开头或重构主题。 
• 不存在机械模板句式。 
• 不存在未经筛查的AI默认表达。 
只有在全部规则均通过后，才允许交付诗歌。
